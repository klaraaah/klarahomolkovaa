Vibe coding: jak postavit web
bez psaní jediného řádku kódu

Termín vibe coding zpopularizoval v roce 2025 Andrej Karpathy. Myšlenka je jednoduchá: popíšete výsledek v normální češtině a AI napíše kód. Pro netechnické podnikatele je to průlom.

Vibe coding není magie, ale je to skutečně jiný způsob práce. Místo učení syntaxe popisujete záměr. Místo psaní HTML říkáte „chci tmavý web s růžovým akcentem, moderním fontem a formulářem na kontakt". A dostanete to.

Co je vibe coding a odkud přišel

Andrej Karpathy — jeden ze zakladatelů OpenAI a šéf AI ve startupu Anduril — v roce 2025 popsal svůj způsob práce s AI: popíšete výsledek, AI vygeneruje kód. Místo psaní syntaxe popíšete v přirozeném jazyce, co chcete, a model dodá implementaci. Vy pak výsledek otestujete a iterujete.

Pro netechnické publikum je to průlom: nemusíte znát Python, HTML ani JavaScript, abyste postavil/a funkční nástroj, web nebo automatizaci.

Klíčová myšlenka: Vibe coding není o kódu. Je o kontextu. Co model „vidí" v danou chvíli — to rozhoduje o kvalitě výsledku.

Čtyři způsoby, jak používat Claude

Anthropic nabízí různá rozhraní pro různé potřeby. Nejsou to čtyři oddělené produkty — sdílejí stejný účet — ale mají různé schopnosti:

💬 Browser / mobil
claude.ai
Klasický chat. Žádná instalace. Ideální pro otázky, psaní textů, brainstorming a jednoduché úkoly. Soubory lze přiložit přes upload.
🖥️ Desktop aplikace
Claude Desktop
Nativní aplikace pro macOS a Windows. Obsahuje Chat, Cowork a Code záložku. Centrum celého pracovního postupu.
⬢ Netechnické úlohy
Cowork (v Desktop)
Agentický režim pro vícekrokové úlohy bez programování. Dáte mu cíl, Claude naplánuje kroky a pracuje sám na vybraných složkách. Ideální pro organizaci souborů, reporty, automatizaci.
💻 CLI / terminál
Claude Code
Nástroj pro vývojáře s plným přístupem k filesystému. Edituje soubory, spouští příkazy, commituje do gitu. Pro netechnické uživatele méně relevantní.

Pro vibe coding webu bez kódu budete používat nejčastěji claude.ai nebo Cowork v Claude Desktop. Claude Code je pro situace, kdy chcete hlubší kontrolu nad soubory projektu.

Co rozhoduje o úspěchu (ne jen chytrý model)

Dnes jsou modely velmi podobně výkonné. Co výsledek skutečně ovlivňuje, je kontext — co všechno model v danou chvíli „vidí":

  • Soubory a přístupy: Má model přístup k vašim souborům, nebo jen k tomu, co napíšete?
  • Jasné instrukce: Víte si model zapamatovat, na čem pracujete, nebo začínáte pokaždé od nuly?
  • Správné nástroje: Má model web search, code execution nebo přístup k vašim aplikacím?
  • Dostatek „paměti": Kontextové okno má limit — při příliš dlouhé konverzaci model zapomíná na začátek.
Prakticky řečeno: „Postav mi web" dá jiný výsledek než „Postav mi jednostránkový web pro kadeřnictví Klára v Třebíči. Barvy: tmavé pozadí, zlatý akcent. Sekce: úvod, ceník, galerie, kontakt s formulářem. Font: moderní sans-serif. Web musí být mobilní."

Jak začít: váš první web s AI

Konkrétní postup, který používám s klienty:

  1. Napište brief. Kdo jste, co nabízíte, pro koho, jaký styl. Čím konkrétněji, tím lépe.
  2. Dejte modelu kontext. Barvy, font, sekce, případně reference na weby, které se vám líbí.
  3. Generujte první verzi. Výsledek bude hrubý — to je normální.
  4. Iterujte konkrétně. „Změň barvu tlačítka na růžovou", „přidej sekci reference", „zkrať hero text".
  5. Ověřte výsledek. Otestujte na mobilu, zkontrolujte formulář, projeďte texty.
Kde vibe coding nestačí: Složitější e-shopy, napojení na platební brány, vlastní databáze nebo specifické integrace. Tam potřebujete buď zkušeného vývojáře, nebo výrazně hlubší technické znalosti.

Kdy je lepší zavolat odborníka

Vibe coding je skvělý nástroj — ale není řešením na všechno. Doporučuji spolupracovat s odborníkem, pokud:

  • Potřebujete web, který skutečně přivádí zákazníky (copywriting, SEO, konverzní architektura)
  • Váš web bude zpracovávat platby nebo citlivá data
  • Chcete mít výsledek za 48 hodin bez učení se HTML
  • Potřebujete WordPress s administrací pro pravidelné změny

Vibe coding vám dá výsledek rychle. Ale zkušenost a strategie dají výsledek, který funguje.

Chcete web rychle a bez starostí?

Postavím vám web do 48 hodin — s copywritingem, SEO a mobilní verzí. Ukážu vám návrh před platbou.
